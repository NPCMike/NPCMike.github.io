OCI 核心概念一覽

Oracle Cloud Infrastructure 的資源組織與 AWS 類似但命名不同：

OCI 概念類比 (AWS)說明
TenancyAccount根租戶，所有資源歸屬
Compartment多 OU/Account 混合邏輯隔離 + policy 邊界
VCNVPC區域內虛擬網路
SubnetSubnetPublic / Private 分割
Dynamic GroupIAM Role (instance profile)讓 compute 取得 API 權限
PolicyIAM PolicyAllow group X to manage Y in compartment Z

建立 Tenancy 與第一個 Compartment

1. 註冊與 Admin 使用者

  1. 前往 cloud.oracle.com 建立 Free Tier 或 Pay-as-you-go
  2. 第一個 user 即 Tenancy Admin，務必啟用 MFA
  3. 下載 API signing key（Console → User → API Keys → Add）
Warning

Never commit ~/.oci/config 或 private key 到 git。使用 OCI Vault 或 CI secret store。

Compute 與 OKE

服務用途管理要點
Compute (VM/BM)一般 workloadShape 選 Flex 可省成本；用 Instance Pool + autoscaler
OKEKubernetesAPI endpoint 設 private；worker 在 private subnet
Autonomous DB託管 DB自動 patch；用 Wallet 或 TLS 連線
Object Storage備份 / static assetsLifecycle policy 轉 Archive / Delete

監控與成本

  • Monitoring — Metrics + Alarms（CPU、LB health）
  • Logging — Service logs → Log group → Streaming 到 SIEM
  • Cost Analysis — 依 compartment / tag 分帳
  • Resource Manager — Terraform stack 部署（推薦 IaC）
Tip

Free Tier 包含 Always Free ARM Ampere（最多 4 OCPU / 24 GB）——適合跑 lab k8s 或 malware analysis sandbox（需網路隔離）。

控制實作
