ABOUT

方景玄（Mike / NPCMike）

我是一名專注於 Windows 系統安全、惡意程式與 C2、逆向工程及 OT/ICS 安全的資安研究者。 目前就讀輔仁大學人工智慧與資訊安全學士學位學程，並於 Leukocyte Lab（LKC-lab）擔任資安研究實習生。 我的工作從白箱漏洞研究、記憶體防禦與程式載入機制，一路延伸到工控場域的威脅建模與防禦監控。

  • Web 與 SaaS 漏洞研究

研究與實作

Windows 載入安全與主動式記憶體防禦

研究 DLL Search Order Hijacking、ASLR、CRT 初始化、SEH、Security Cookie 與 PE 載入流程， 並持續探索 Hardened ASLR 與主動式記憶體防禦方法。

WebPhantom 自動化檢測平台

開發網站自動化檢測平台，建立頁面蒐集、差異追蹤、風險報告流程，並探索 AI 輔助漏洞分析與安全測試自動化。

Open-source SaaS Vulnerability Research

對約 98 個開源 SaaS 專案進行本機白箱安全檢視，涵蓋 SSRF、IDOR、授權繞過、資訊洩露與程式碼執行風險； 以 Docker 建立端到端驗證、PoC、誤報排除與漏洞證據流程。

Reverse Engineering 與 OT/ICS

針對 Live2D Cubism 與 Windows 應用程式進行靜態、動態分析，並研究 Industroyer2 設定資料、 IEC 60870-5-104 目標與 SCADA 攻擊行為。

HexStrike AI 課程與安全實驗

規劃 AI Red Team、MCP 與自動化滲透測試內容，設計假設、漏洞驗證、PoC、Exploit 與黑箱測試實作 Lab。

CVE 復現與 C2 研究

完成 CVE-2025-29927 復現研究，並整理 C2 類型、常用平台、技術鏈與相關防禦觀察。
